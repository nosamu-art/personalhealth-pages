personalhealth

プライバシーポリシー

このポリシーはpersonalhealthがGoogle Healthから取得するデータに適用します。

取得する情報と利用目的

利用者が許可した運動・位置情報・睡眠・健康指標・食事・プロフィール・設定・デバイス情報を取得し、利用者自身の記録の保存と可視化に使います。接続に必要な認証トークンも保存します。

保存と共有

データと認証情報は利用者が管理するローカル環境に保存します。本人の許可なく第三者に提供しません。

Google APIから取得した情報の利用はGoogle API Services User Data PolicyのLimited Use要件に従います。

削除

データは利用者が削除するまで保存します。保存済みデータと認証情報はローカル環境から削除できます。Googleへのアクセス許可はGoogleアカウントの接続設定で取り消せます。

連絡先

お問い合わせはOAuth同意画面に記載のメールアドレスへお願いします。
