プライバシーポリシー

personalhealthは本人の健康・活動データを管理する個人用アプリです。このポリシーはアプリが取得するデータの取り扱いを説明します。

取得する情報

本人がOAuthなどで許可した範囲のデータをGarmin、Google Health、Withingsから取得します。Google Healthでは運動・歩数・距離・位置情報を含む運動原本、睡眠、心拍・HRV・体重・血中酸素などの健康指標、食事・水分の記録、心電図・不整脈通知、プロフィール・設定・登録デバイスの情報を取得対象とします。実際に保存される項目はアカウントに存在する記録と許可した範囲によります。

APIへ接続するためのアクセストークンと更新用トークンも保存します。Googleのパスワードは保存しません。

利用目的

本人が自分の記録を保存して活動・睡眠・健康指標の履歴や推移を確認するために利用します。ローカルの可視化画面とJSON参照に使います。広告、販売、第三者への提供、AIモデルの学習には利用しません。

保存場所とアクセス

健康データと認証情報は本人の自宅Ubuntuのローカル領域に保存します。認証ファイルは本人のユーザーのみが読み書きできる権限で保存します。ローカルの可視化画面にログイン機能はなく、同じLANで指定アドレスへ接続できる端末からデータを閲覧できます。

このGitHub Pagesサイトと公開リポジトリには健康データと認証情報を置きません。

共有と外部送信

現在の実装は取得した健康データを第三者のサービスへ自動送信しません。LLMへの送信・質問処理も未実装です。APIへの接続時は認証情報と取得条件を取得元サービスへ送信します。

Google APIから取得した情報の利用はGoogle API Services User Data PolicyのLimited Use要件に従います。

保存期間と削除

データは本人が削除するまでローカルに保存します。自動削除の保存期間は設定していません。本人はUbuntu上の保存済みデータと認証ファイルを削除できます。

Googleアカウントの接続設定からpersonalhealthへの許可を取り消せます。許可を取り消すとGoogleからの新しい取得はできなくなります。既にローカルへ保存したデータは別途削除します。

変更と連絡先

データの取得範囲や利用方法を変更する場合はこのポリシーを更新します。
